# Mitos 1 — Penelitian Komputasi Harus Membangun Software

## MITOS

Penelitian komputasi harus menghasilkan aplikasi atau software sebagai hasil utamanya.

## KENYATAAN

Penelitian komputasi tidak harus menghasilkan produk software sebagai tujuan utama.

Software dapat berfungsi sebagai **testbed** atau alat bantu untuk mengukur dan membuktikan bahwa metode atau algoritma yang diusulkan lebih baik, lebih efisien, atau lebih akurat dibandingkan metode yang sudah ada.

---

## 1.1 Penelitian vs Pengembangan Software

Pengembangan software berfokus pada membangun produk atau sistem yang dapat digunakan.

Sedangkan penelitian berfokus pada:

- Pertanyaan ilmiah
- Kontribusi pengetahuan
- Eksperimen
- Evaluasi

Dalam penelitian komputasi, software dapat dibuat karena peneliti membutuhkan alat untuk melakukan eksperimen dan evaluasi.

Dengan demikian, membuat software tidak otomatis berarti melakukan penelitian.

---

## 1.2 Mengapa Software Bisa Tetap Dibuat?

Ketika penelitian mengusulkan perbaikan algoritma atau metode, peneliti membutuhkan implementasi agar metode tersebut dapat diuji.

Program yang dibuat berfungsi sebagai **sarana eksperimen**, bukan otomatis menjadi kontribusi penelitian itu sendiri.
